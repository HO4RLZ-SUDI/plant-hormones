# ฮอร์โมนพืช (Plant Hormones)

เว็บไซต์นำเสนอเรื่องฮอร์โมนพืช 5 ชนิด (ออกซิน, จิบเบอเรลลิน, ไซโทไคนิน, กรดแอบไซซิก, เอทิลีน) — ไฟล์เดียว HTML/CSS/JS ไม่ใช้เฟรมเวิร์ก

ดูเว็บไซต์: https://ho4rlz-sudi.github.io/plant-hormones/

## ผู้จัดทำ

1. นายเปรมศักดิ์ ขาวทอง — เลขที่ 1
2. นายณกรณ์ ว่องวงศกร — เลขที่ 4
3. นายดุลยวัต จันทร์แจ้ง — เลขที่ 5
4. นายธนภัทร ชุมแก้ว — เลขที่ 6
5. นายธนภูมิ แก้ววิลาศ — เลขที่ 7
6. นายรณกร เกื้อเสนาะ — เลขที่ 18

แก้ไขรายชื่อได้ที่ตัวแปร `MEMBERS` ใน `index.html` (หน้าแรกและหน้าผู้จัดทำอ่านจากชุดข้อมูลเดียวกัน)
